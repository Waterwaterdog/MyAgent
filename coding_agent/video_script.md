## 中文视频发言稿（建议语速适中，约 1分40秒）

“各位评委老师好。今天我演示的项目是我独立开发的轻量级编程智能体，Coding Agent。

与直接调用 LangChain 等现成框架不同，这个项目从零开始，自主实现了 Agent 的核心逻辑，包括上下文管理、工具的 Schema 定义与本地调度、以及基于大模型原生 Tool Calling 的循环机制。这样做的目的是为了完全掌控代码的运行逻辑，并保证系统架构的透明与轻量。

（开始在终端运行 `python main.py` 并输入计算器任务）
现在，我给 Agent 下达一个真实的编程任务：编写一个包含加减乘除的 Python 计算器，并编写对应的单元测试，最后自动运行测试。

（画面展示 Agent 思考和工具调用）
大家可以看到，Agent 接收到任务后，首先自动分析了需求，并触发了 `write_file` 工具，在本地创建了源文件和测试文件。接着，它自主调用了 `run_command` 工具来执行测试命令。
如果测试中发现错误，Agent 会读取错误输出，并自动调用 `edit_file` 工具去修改代码，直到测试完全通过。整个过程不需要人工干预。

（画面展示生成的文件和安全代码）
除了自动编程，我在设计时也非常注重安全性。比如在文件操作中，我加入了绝对路径校验，防止目录穿越；在命令执行时，设置了超时中断和高危命令的黑名单拦截。

这个项目虽然精简，但完整实现了现代 Agent 的核心闭环，并且拥有极强的可扩展性。我的演示完毕，谢谢大家。”
